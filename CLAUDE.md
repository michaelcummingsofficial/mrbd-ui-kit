# mrbd-ui-kit

A pnpm monorepo with two packages. `packages/mrbd-ui-kit` is the published React component library for Meta Ray-Ban Display web apps. `packages/example` is the Next.js app at mrbd.fun that serves as both the live demo and the marketing site.

`AGENTS.md` is the guide for building an app *with* the kit. Follow it whenever you write display UI, in the example app or in the kit's own components.
